MATÉRIA REATIVA - CENTRAL DE DOCUMENTAÇÃO

ESTRUTURA:

materia-reativa-documentacao/
│
├── index.html
│
├── css/
│   └── style.css
│
├── js/
│   └── script.js
│
├── img/
│   └── coloque suas imagens aqui
│
└── documentos/
    └── coloque seus PDFs aqui


COMO ABRIR:

1. Extraia o ZIP.
2. Abra a pasta no VS Code.
3. Abra o index.html.
4. Se tiver Live Server, clique com o botão direito no index.html
   e selecione "Open with Live Server".


DOCUMENTOS:

Coloque os PDFs dentro da pasta "documentos".

Os nomes utilizados atualmente no site são:

canvas.pdf
requisitos.pdf
referencial-teorico.pdf
prototipo.pdf
documentacao-tecnica.pdf
planejamento.pdf
fluxograma.pdf
banco-dados.pdf


PARA ADICIONAR NOVOS DOCUMENTOS:

Copie um dos cards existentes no index.html e altere:

- título
- descrição
- categoria
- caminho do PDF
